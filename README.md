# StudyBees

## SkillBridge


SkillBridge ist eine Web-App, die zwei Zielgruppen miteinander verbindet: kleine und mittelständische IT-Unternehmen auf der einen Seite sowie IT-Freelancer auf der anderen.

Der Arbeitsmarkt ist derzeit stark umkämpft, und viele Unternehmen investieren vorsichtiger. Dadurch wird es zunehmend üblich, externe Fachkräfte für zeitlich begrenzte Projekte zu beauftragen. Genau an dieser Stelle setzt SkillBridge an: Die Plattform bringt Unternehmen, die kurzfristig Unterstützung brauchen, mit Freelancern zusammen, die passende Aufträge für ihr Skillset suchen.

Das Grundprinzip ist einfach: Unternehmen veröffentlichen Projekte, Freelancer können sich darauf bewerben. Über eine Suchfunktion mit Filtern und einer Empfehlungsfunktion finden beide Seiten passende Angebote beziehungsweise passende Kandidaten.
Ein personalisiertes Dashboard sorgt für Übersicht und schnellen Zugriff auf die wichtigsten Funktionen. Freelancer können außerdem ein Skillset anlegen und ihre Projekthistorie pflegen, um sich besser zu präsentieren. Für Unternehmen gibt es eine Projektverwaltung, über die Projekte erstellt und der Fortschritt bzw. die Leistung verwaltet werden können.
